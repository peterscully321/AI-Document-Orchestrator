# 🎨 Interactive UI Guide

## Quick Start

1. **Install Streamlit** (if not already installed):
   ```bash
   pip install -r requirements-ui.txt
   ```

2. **Run the UI**:
   ```bash
   streamlit run app.py
   ```

3. **Open your browser** - Streamlit will automatically open at `http://localhost:8501`

## Features

### 📝 Document Generator
- Generate comprehensive documents on any topic
- Supports multiple output formats (Text, PDF, Google Docs)
- Includes research, summarization, and quality checks
- Upload local files to include in research

### 📄 Summarizer
- **Research Topic Mode**: Research and summarize any topic
- **Paste Content Mode**: Summarize pasted content directly
- Creates structured notes with key points
- Shows source references

### ✍️ Blog Writer
- Create engaging blog posts
- Choose writing tone (Professional, Casual, Friendly, etc.)
- Set target length
- Research-backed content
- Quality assurance included

### ⚙️ Settings
- View API configuration status
- Check model information
- System information

## UI Features

- 🎨 **Modern Design**: Beautiful gradient buttons and cards
- 📱 **Responsive Layout**: Works on desktop and mobile
- ⚡ **Real-time Progress**: See progress bars and status updates
- 💾 **Download Options**: Download generated content
- 🔍 **Smart Navigation**: Easy sidebar navigation

## Usage Tips

1. **Document Generator**: Best for comprehensive, research-backed documents
2. **Summarizer**: Quick summaries of topics or pasted content
3. **Blog Writer**: Perfect for creating blog posts with specific tone and length

## Troubleshooting

- **UI not loading**: Make sure the UI dependencies are installed (`pip install -r requirements-ui.txt`)
- **API errors**: Check your `.env` file has correct API keys
- **Slow generation**: This is normal - the system performs research, summarization, and quality checks
